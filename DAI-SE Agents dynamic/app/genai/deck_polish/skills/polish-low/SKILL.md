# Deck polish - Low (clean-up)

The user asked for slides that stay close to Rockwell's standard layouts. Polish means
removing defects, never redesigning.

What is fixed, all by rules in code (no model call at this level):

- A stamped classification label that repeats the one the layout already prints.
- A shape that runs off the slide is pulled back onto it.
- Text below the type-scale floor (10 pt) is raised to the floor.
- A colour that is not in the Rockwell palette (or a tint of a theme accent) becomes the
  nearest brand colour.
- UK spelling becomes US spelling, on the slides and in the speaker notes.

What is never done at this level:

- Moving, resizing or restyling any element.
- Adding or removing content.
- Touching anything the template placed: the frame, the logos, text printed on a
  template graphic.

Problems rules cannot fix (two text blocks running into each other, a wall of text, a
large empty band) are listed for the user, not changed.
