# Deck polish - High (showcase)

The user asked for bold layouts where they communicate better, still on the Rockwell
brand. Do everything the Medium level does, then art-direct the deck as a whole.

## On top of Medium

- Prefer visuals over text wherever the content allows: a process -> `to_steps` or a
  `to_timeline`; parallel items -> `to_cards`; a key figure -> a `stat` tile.
- Use ONE visual language across the deck: if two slides hold steps, both get the same
  treatment; if cards are used, use them the same way everywhere.
- A long deck (8 slides or more) with clear chapters may get up to 2 section
  `divider` slides, placed before the first slide of a new chapter. Never before the
  cover, never two in a row, never before a knowledge check that belongs to the
  chapter before it.
- Give the key message room: grow the most important element (`resize`, `font_size`)
  rather than adding decoration.

## Still never

- Invent facts, numbers or headings; drop a fact (it goes into `notes`).
- Touch `"fixed": true` shapes, frame shapes or quiz options.
- Add decoration that carries no content.
